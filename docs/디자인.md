# 화면 디자인: 「먹과 종이」 퍼즐 (v1.0.0)

- 정본: 디자인 명세 `DESIGN.md`(확정, 앱 저장소 밖), `tokens-puzzle.css`, `mockup-puzzle.html`, `cat.svg`. 값이 다르면 그 파일이 이긴다.
- 회사 브랜드와 바둑 첫걸음 「달밤 대국실」은 따르지 않는다(요청 사항).
- 이 문서는 앱에 **어떻게 옮겼는지**만 적는다.

## 2. 원칙을 옮긴 방법

- **판이 주인공**: 색은 판 안(구역 색, 선택 칸)과 행동 단추 하나(`--acc`)에만. 앱 바·독은 바탕과 같은 면.
- **면 단계**: 바탕(`--canvas`) → 카드(`--surface`) → 카드 안 칸(`--surface-2`). 그림자·흐림·그라데이션 0. 떠 있는 층(독·시트·대화상자)은 `--ring-strong` 머리카락 선.
- **주 단추 하나**: 홈 「이어서」, 차시 카드 「다음」, 결과 「다른 퍼즐/다음 차시」. 풀기 화면(숫자·칸 고르기)에는 주 단추가 없다. 힌트 카드 안 「왜 그럴까/이렇게 해요/그대로 하기」만 주 단추.
- **알림 세 겹**: 맞음·틀림 = 면(`--ok-soft`/`--bad-soft`) + 고양이 표정(기쁨/아쉬움) + 문장. 규칙 어김 = 칸 테두리 `--conflict` + 고양이 아쉬운 표정 + 판 아래 「규칙 어김 · 고양이끼리 닿았어요」 줄.
- **모션**: 누름 120ms, 놓기·스위치 180ms, 카드 등장 240ms, 시트 280ms, 보상(결과 고양이·별·시간)만 360ms 스프링. 줄이기 설정에서 모두 0.

## 3. 판

- **스도쿠**: 칸 48 단위 SVG. 처음 숫자 700 `--digit-given`, 내가 넣은 숫자 400 `--digit-user`(색 + 굵기). 숫자 크기는 칸의 0.54(넓은 화면 0.62). 메모는 화면에서 14px이 되게 판의 실제 폭을 재어 SVG 단위로 바꾼다(`APP.boardScale`). 선택 칸 `--cell-sel` + 3px `--focus` 선(귤색 `--acc`는 선택 칸 위 대비 2.83이라 쓰지 않음).
- **고양이 자리**: 구역 = 색 + 무늬(8px 반복 10종) + 3px 경계. 구역 색 배정은 DESIGN.md 9-5 규칙대로 **이웃 구역끼리 색약에서 헷갈리는 쌍(1–4, 2–7, 2–10, 3–7, 3–8, 5–10, 6–9, 7–8)이 붙지 않게** 구역 번호 순서로 가장 작은 번호를 고른다(`zoneMap`). 피할 수 없으면 남은 가장 작은 번호(무늬가 다르므로 구별됨). 한 판 안에서 색은 겹치지 않는다(힌트 문장이 구역을 이름으로 가리키므로).
- **구역 이름**: 힌트·화면 읽기에서 「하늘색 점무늬 구역」처럼 색 + 무늬. 무늬를 끄면 색 이름만. 색 이름은 DESIGN.md 9-5의 뿌리 색(주황, 하늘, 청록, 노랑, 파랑, 주홍, 자주, 회색, 모래, 연보라).
- **칸 단추**: 판 SVG 위에 투명 단추 격자를 겹쳤다(`role="grid"`·`gridcell`, 로빙 tabindex). 누르기·키보드 초점·화면 읽기 이름(「3줄 2칸, 하늘색 점무늬 구역, 비어 있음」)을 이 단추가 맡는다. 초점은 칸 안쪽 3px `--focus` 고리.
- **자동 점**: 고양이를 놓으면 둘 수 없는 칸에 흐린 점(설정에서 끔). 사용자가 한 ×와 구별된다.
- **힌트 표시**: 1단계 볼 곳 밖을 `--canvas` 62%로 덮음(스도쿠는 볼 곳을 `--acc-soft`로도 칠함: 흰 격자에서는 덮개만으로 잘 안 보여서), 2단계 관련 칸 점선, 3단계 놓을 칸·지울 칸 `--acc-ink` 점선 + × 미리보기, 스도쿠 지울 후보는 메모 숫자에 사선.

## 4. 화면 배치

| 폭 | 배치 |
| --- | --- |
| 900 미만 | 한 열, 내용 최대 560. 탭 화면(놀이터·자유 연습·기록·더보기)은 아래 떠 있는 독, 문제·풀기 화면은 독 없이 도구 줄 |
| 900 이상 | 왼쪽 레일 88(독과 같은 4칸). 풀기 화면은 가운데 판 600(`min(600px, 100dvh − 176px)`) + 오른쪽 패널 400(퍼즐 이름 카드 → 힌트 카드 → 도구 줄 → 숫자 단추 5×2) |

- 휴대폰에서 판은 폭을 꽉 채우되, 세로가 짧으면 아래 도구·숫자 단추가 한 화면에 들어오게 판 크기를 세로 높이로도 묶는다(최소 288).
- 휴대폰에서 힌트 카드를 펼치면 도구 줄·숫자 단추를 잠시 접는다(판 아래 카드, 판을 가리지 않음).

## 5. 시안과 다르게 한 것

| 무엇 | 시안 | 앱 | 이유 |

| 첫 실행 홈 | 「오늘의 퍼즐부터 해 볼까요」 + 시작하기 | 같음. 보조 문장에 「차근차근 배우려면 길에서 1차시부터」를 붙임 | 아이는 1차시부터가 낫고, 주 단추는 하나로 둬야 해서 글로만 안내 |
